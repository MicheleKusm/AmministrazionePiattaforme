# msplatformapi

Microservizio backend per la console di **Amministrazione Piattaforme**.

## lo Stackk utilizzato

- Java 21
- Spring Boot 3.5.x
- Maven
- Spring Data JPA + Oracle JDBC
- OpenAPI + Actuator

## Avvio del PROGETTONE

```bash
mvn clean spring-boot:run
```

Endpoint health custom: `GET /platform/health/live`
